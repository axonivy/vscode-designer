# Agentic Engineering

The Axon Ivy Designer comes with rich tooling to support your AI driven Agent coding experience.

Contributions for copilot are designed as auto-enabled tools and skills,
that help the agent to work effectively with ivyprojects.

To use these tools and skills in a third-party harness, like Claude Code or Copilot CLI,
please follow the instructions in the [MCP](./mcp/mcp.md) and [Skills](./skills/skills.md) section.
